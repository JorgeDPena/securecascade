# securecascade
**291 caracteres:**  > Sistema de criptografia em C (libsodium) baseado no conceito de 'Wall of Entropy': um buffer circular de tokens efêmeros que expiram e disparam crypto-shredding automático dos dados dependentes. Usa pool de memória em arena, criptografia em camadas (AEAD/onion) e testes com ASan/UBSan/TSan.
